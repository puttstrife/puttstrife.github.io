BMO

BMO is an experiment in making everyday writing help feel less like a correction and more like a friendly companion.

Product design & development·Desktop widget · Local writing assistance

The Situation

Writing help works better when it does not feel like an interruption.

Grammar tools are useful, but they can also feel cold, crowded, or overly formal for a quick sentence-level check.

I wanted to explore a smaller interaction: type or dictate a sentence, receive a clean revision, and get a little bit of character in return.

The Approach

A tiny, expressive writing companion.

BMO is a frameless, always-on-top macOS widget. A person enters or dictates text; when a local Ollama model is available, the app asks it to return a corrected version focused on grammar, spelling, and punctuation.

The interface responds with one of 30 local face states, can speak a response through a local voice sidecar, and has a companion browser extension for bringing the interaction into a page.

Key Moments

Make a small correction feel alive.

How It Works

Keep the request as narrow as the task.

What It Enables

Focused revisions

The local-model prompt is designed to return corrected grammar, spelling, and punctuation.

Expressive feedback

Thirty local SVG expressions let the companion react to the interaction.

Voice options

Text can be dictated through browser capabilities and spoken through an optional local voice service.

Two surfaces

The idea extends from the desktop widget to a browser extension that can inject its interface into pages.

Conclusion

“A correction can be practical without feeling impersonal.”

BMO is an experimental personal project. Its text model can run locally when Ollama is used locally; speech and optional voice features have their own setup and privacy considerations. The project uses a recognizable character as a personal exploration and is not affiliated with its rights holders.
